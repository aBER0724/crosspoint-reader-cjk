# Web 服务器指南
[English](./webserver.md) · **简体中文** · [日本語](./webserver-JA.md)

本指南介绍如何将 CrossPoint Reader 连接到 WiFi，以及如何使用内置 Web 服务器从电脑或手机上传文件。

## 概述

CrossPoint Reader 内置的 Web 服务器可让你：

- 从同一 WiFi 网络中的任何设备无线上传文件
- 浏览和管理设备 SD 卡中的文件
- 创建文件夹来整理书库
- 删除文件和文件夹

## 准备工作

- CrossPoint Reader 设备
- WiFi 网络
- 一台连接到**同一 WiFi 网络**的电脑、手机或平板电脑

---

## 步骤 1：打开 WiFi 屏幕

1. 从主菜单或文件浏览器进入**设置**屏幕
2. 选择 **WiFi** 选项
3. 设备会自动开始扫描可用网络

1. 选择**加入网络**。
2. 如果已保存 Wi-Fi 凭据，CrossPoint 会先尝试连接上次使用的网络，然后按信号强度从高到低依次尝试其他可见的已保存网络。按**返回**可取消，按**确认**可停止自动连接并显示网络列表。
3. 如果显示网络列表，请从扫描结果中选择一个 2.4 GHz Wi-Fi 网络。
4. 如果系统提示，请输入密码。
5. 如果希望阅读器下次自动重新连接，请保存凭据。

## 步骤 2：连接到 WiFi

### 查看可用网络

扫描完成后，你会看到可用 WiFi 网络列表，其中包含以下标记：

- **信号强度条**（`||||`、`|||`、`||`、`|`）- 表示连接质量
- **`*` 符号** - 表示该网络受密码保护（已加密）
- **`+` 符号** - 表示你之前保存过该网络的凭据

<img src="./images/wifi/wifi_networks.jpeg" height="500">

### 选择网络

1. 使用**左/右**（或**音量加/减**）按钮在网络列表中移动
2. 按**确认**选择高亮显示的网络

### 输入密码（适用于加密网络）

如果网络需要密码：

1. 屏幕上会显示键盘
2. 使用导航按钮选择字符
3. 每输入一个字符时按**确认**
4. 输入完成后，选择键盘上的**完成**选项

<img src="./images/wifi/wifi_password.jpeg" height="500">

**注意：** 如果你之前连接过此网络，设备会自动使用已保存的密码。

### 连接过程

设备在建立连接时会显示“正在连接...”。此过程通常需要 5-10 秒。

### 保存凭据

如果这是一个新网络，系统会询问是否保存密码：

- 选择**是**可保存凭据，以便下次自动连接（注意：这些凭据以明文形式存储在设备的 SD 卡上。请勿将此功能用于敏感网络。）
- 选择**否**可连接网络但不保存凭据

---

## 步骤 3：连接成功

连接成功后，屏幕会显示：

- **网络名称**（SSID）
- **IP 地址**（例如 `192.168.1.102`）
- 包含临时管理令牌的 **Web 服务器 URL**

<img src="./images/wifi/wifi_connected.jpeg" height="500">

**重要提示：** 请记下 IP 地址。你需要使用它从电脑或手机访问 Web 界面。

---

## 步骤 4：访问 Web 界面

### 从电脑访问

1. 确保电脑与 CrossPoint Reader 连接到**同一 WiFi 网络**
2. 打开任意 Web 浏览器（推荐使用 Chrome）
3. 扫描二维码，或在浏览器地址栏中输入设备上显示的完整 URL
   - 示例：`http://192.168.1.102/?token=...`
4. 按 Enter 键

### 从手机或平板电脑访问

1. 确保手机或平板电脑与 CrossPoint Reader 连接到**同一 WiFi 网络**
2. 打开移动浏览器（Safari、Chrome 等）
3. 扫描二维码，或在地址栏中输入设备上显示的完整 URL
   - 示例：`http://192.168.1.102/?token=...`
4. 点击前往

---

## 步骤 5：使用 Web 界面

### 主页

主页会显示：

- 设备状态和版本信息
- WiFi 连接状态
- 当前 IP 地址
- 可用内存

导航链接：

- **Home** - 返回状态页面
- **File Manager** - 使用文件管理功能

<img src="./images/wifi/webserver_homepage.png" width="600">

### 文件管理器

点击 **File Manager** 使用文件管理功能。

#### 浏览文件

- 文件管理器会显示 SD 卡中的所有文件和文件夹
- **文件夹**以黄色高亮，并带有 📁 图标
- **EPUB 文件**以绿色高亮，并带有 📗 图标
- **所有其他文件**不高亮，并带有 📄 图标
- 点击文件夹名称可进入该文件夹
- 使用顶部的面包屑导航返回上级文件夹

<img src="./images/wifi/webserver_files.png" width="600">

#### 上传文件

1. 点击右上角的 **📤 Upload** 按钮
2. 点击 **Choose File**，然后从设备中选择文件
3. 点击 **Upload**
4. 进度条会显示上传状态
5. 上传完成后，页面会自动刷新

<img src="./images/wifi/webserver_upload.png" width="600">

#### 创建文件夹

1. 点击右上角的 **📁 New Folder** 按钮
2. 输入文件夹名称（不得包含字符 \" * : < > ? / \\ |，也不能是 . 或 ..）
3. 点击 **Create Folder**

你可以按类型、作者、系列或文件类型整理书库。

#### 删除文件和文件夹

1. 点击任意文件或文件夹旁边的 **🗑️**（垃圾桶）图标
2. 在弹出的对话框中确认删除
3. 点击 **Delete** 永久删除该项目

**警告：** 删除操作是永久性的，无法撤销！

**注意：** 文件夹必须为空才能删除。

#### 移动文件

1. 点击任意文件旁边的 **📂**（文件夹）图标
2. 输入文件夹名称，或从下拉列表中选择一个文件夹
3. 点击 **Move** 移动文件

**注意：** 输入不存在的文件夹名称会导致以下错误：“Failed to move: Destination not found”

#### 重命名文件

1. 点击任意文件旁边的 **✏️**（铅笔）图标
2. 输入文件名（不得包含字符 \" * : < > ? / \\ |，也不能是 . 或 ..）
3. 点击 **Rename** 永久重命名该文件

## 使用命令行管理文件

高级用户可以在设备处于文件上传模式时，使用 `curl` 直接从终端管理文件。详细文档请参阅[此处](./webserver-endpoints.md)。

## 安全注意事项

- Web 服务器在端口 80（标准 HTTP）上运行
- 文件管理、设置、Wi-Fi、OPDS、WebDAV 和上传 API 均需要设备屏幕上显示的临时管理令牌
- 同一网络中的客户端仍然可以查看 HTML 页面和基本设备状态
- 只有当 WiFi 屏幕显示“已连接”时，才能访问 Web 服务器
- 退出 WiFi 屏幕后，Web 服务器会自动停止
- 为确保安全，请仅在可信的专用网络中使用

---

## 技术细节

- **支持的 WiFi：** 2.4 GHz 网络（802.11 b/g/n）
- **Web 服务器端口：** 80（HTTP）
- **最大上传大小：** 每个文件 512 MB，同时受 SD 卡可用空间限制
- **最长上传时间：** 每个文件 15 分钟
- **存储空间预留：** 通过浏览器、WebSocket 和 WebDAV 上传时，SD 卡至少会保留 8 MB 可用空间
- **浏览器兼容性：** 所有现代浏览器（Chrome、Firefox、Safari、Edge）

---

## 使用技巧和最佳实践

1. **使用文件夹整理** - 上传前先创建文件夹，让书库保持井然有序
2. **检查信号强度** - 较强的信号（`|||` 或 `||||`）能提供更快、更可靠的上传速度
3. **上传多个文件** - 可以一次选择并上传多个文件；文件管理器会将其加入队列，并在整批文件上传完成后刷新页面
4. **使用清晰的名称** - 为文件夹起一个清楚说明内容的名称（例如“SciFi”“Mystery”“Non-Fiction”）
5. **保存凭据** - 保存 WiFi 密码，以便日后快速重新连接
6. **完成后退出** - 按**返回**退出 WiFi 屏幕并节省电量

---

## 退出 WiFi 模式

文件上传完成后：

1. 按 CrossPoint Reader 上的**返回**按钮
2. Web 服务器会自动停止
3. WiFi 会断开连接以节省电量
4. 设备会返回上一个屏幕

上传的文件会立即出现在文件浏览器中！
