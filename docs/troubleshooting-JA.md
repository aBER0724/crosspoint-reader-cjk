### ネットワーク上で端末が見つからない

**問題:** ブラウザーに「接続できません」または「サイトにアクセスできません」と表示される

**対処方法:**

1. 両方の端末が**同じWi-Fiネットワーク**に接続されていることを確認する
   - パソコンまたはスマートフォンのWi-Fi設定を確認する
   - CrossPoint Readerに「接続完了」と表示されていることを確認する
2. IPアドレスを再確認する
   - 入力に誤りがないことを確認する
   - 先頭に `http://` を付ける
3. VPNを使用している場合は無効にする
4. ネットワークで「クライアント分離」が有効になっている場合は、ネットワーク管理者に確認する

### 接続が切れる、またはタイムアウトする

**問題:** Wi-Fi接続が不安定

**対処方法:**

1. Wi-Fiルーターに近づける
2. 端末の信号強度を確認する（`||` 以上が目安）
3. ほかの機器からの電波干渉を避ける
4. 利用可能であれば、別のWi-Fiネットワークを試す

### アップロードに失敗する

**問題:** ファイルのアップロードが完了しない、またはエラーが表示される

**対処方法:**

1. 有効な `.epub` ファイルであることを確認する
2. SDカードに十分な空き容量があることを確認する
3. まず小さいファイルをアップロードして動作を確認する
4. ブラウザーを再読み込みして、もう一度試す

### 保存したパスワードで接続できない

**問題:** 保存済みの認証情報で端末が接続できない

**対処方法:**

1. 接続に失敗すると「ネットワークを忘れますか？」と表示される
2. **はい**を選択して、保存済みパスワードを削除する
3. 再接続してパスワードを入力し直す
4. 新しいパスワードを保存する
