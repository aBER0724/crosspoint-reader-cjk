### 在网络中找不到设备

**问题：** 浏览器显示“无法连接”或“无法访问此网站”

**解决方法：**

1. 确认两台设备连接到**同一个 WiFi 网络**
   - 检查电脑或手机的 WiFi 设置
   - 确认 CrossPoint Reader 显示“已连接”状态
2. 再次核对 IP 地址
   - 确保输入正确
   - 确保地址以 `http://` 开头
3. 如果正在使用 VPN，请尝试将其关闭
4. 某些网络启用了“客户端隔离”，请咨询网络管理员

### 连接中断或超时

**问题：** WiFi 连接不稳定

**解决方法：**

1. 靠近 WiFi 路由器
2. 检查设备上的信号强度（至少应为 `||` 或更强）
3. 避免其他设备造成的干扰
4. 如果有其他 WiFi 网络可用，请尝试切换网络

### 上传失败

**问题：** 文件上传无法完成或显示错误

**解决方法：**

1. 确保文件是有效的 `.epub` 文件
2. 检查 SD 卡是否有足够的可用空间
3. 先尝试上传较小的文件进行测试
4. 刷新浏览器页面后重试

### 已保存的密码无法使用

**问题：** 设备无法使用已保存的凭据连接网络

**解决方法：**

1. 连接失败时，系统会提示“忘记网络”
2. 选择**是**以删除已保存的密码
3. 重新连接并再次输入密码
4. 选择保存新密码
